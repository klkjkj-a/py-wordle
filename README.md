# py-wordle
Wordle 小游戏的 Python 实现。使用 Python 3.12.2.
## pyWordle.py
以命令行界面呈现。需要和 words.txt 在同一目录下才能运行。
## pyWordle_tk.py
调用 tkinter 库，以图形界面呈现，可以选择单词长度。需要和 words.txt 在同一目录下才能运行。
## words.txt
词库。Python 从这个文件抽取单词。

词库单词不齐全，一些形容词和副词缺少比较级和最高级。
